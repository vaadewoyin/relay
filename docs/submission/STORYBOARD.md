## Record on Windows 11 with WSL2

1. Rehearse offline first via `bash scripts/demo.sh offline`. For the final take, run live using the [dedicated Notion setup](../../backend/README.md#notion-demo) and the [demo guide](../DEMO.md). Run the printed Vite and simulator commands in separate WSL terminals. Keep those terminals and Swagger off camera. Keep the API on loopback.
2. Use a fresh synthetic Notion workspace or freshly provisioned demo databases for the final take so the current-owner row reflects this run. Retain previous records. If starting with an existing row, check the pending status and verify the final current-owner row before recording the write-back. A fresh local database does not reset Notion. Verify import and perform one live analysis before filming the queue.
3. Open Notion in a clean browser window. Hide browser address bar, bookmarks, account controls, notifications, and developer tools. Frame only the synthetic report and action fields. Zoom text until excerpts are readable. Keep the simulator framebuffer centered and the gesture controls visible if they help follow the action.
4. On Windows, use **Win+Shift+R**, select just the window content, then **Start** and **Stop** in Snipping Tool. Save clips in shot order. If two views do not fit in one crop, record separate clips. Record narration on the Windows host using Clipchamp audio recording or import a separate narration take. Host narration is independent of Relay's gesture UI. [Windows capture guide](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots) · [Clipchamp editing guide](https://support.microsoft.com/en-us/clipchamp/how-to-edit-a-video-in-clipchamp)
5. After recording the pending receipt, publish that receipt off camera via `POST /notion/receipts/{receipt_id}/sync` in local Swagger. Reload the Notion tabs, then reopen the receipt in the simulator to capture the synced state. If publication is still pending, resolve it or keep pending visible and reshoot after verified sync. Keep the same run across all shots.
6. Assemble the clips in the order above, adding spoken narration and captions. Crop or cover private record IDs including partial UUIDs on wearable evidence, local receipt IDs, workspace names, and URLs. Use a plain opaque mask if needed. Keep source quotes, acceptance choice, counts, and sync status visible. Export an MP4 at 1080p if available. Aim for 2:50 and confirm the actual file ends by 3:00. Watch the exported file start to finish, then test the uploaded link signed out.
